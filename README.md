# Viractal TCG - Card Database Engine

An interactive, responsive database engine and web viewer for the Viractal Trading Card Game, managing 270+ structured card entities with client-side real-time multi-attribute filtering.

## 🔗 Live Demo
**[https://viractal-cards.lkm-lab.workers.dev](https://viractal-cards.lkm-lab.workers.dev)**

## 🛠️ Tech Stack
- **Frontend:** Vanilla JavaScript (ES6+), Modern CSS Grid & Flexbox, HTML5
- **Data Architecture:** Structured JSON (270+ Entities)
- **Deployment:** Cloudflare Serverless Edge Network
